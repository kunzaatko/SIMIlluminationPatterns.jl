Interface

Any illumination pattern is a subtype of the IlluminationPattern

SIMIlluminationPatterns.IlluminationPattern — Type
IlluminationPattern{N}

Super type for N-dimensional illumination patterns.

source

Such an illumination pattern can be sampled at points within the object plane/space by intensity(IP, r).

SIMIlluminationPatterns.intensity — Method
@interface intensity(ip::IlluminationPattern{N}, r::SVector{N})
@interface intensity(ip::IlluminationPattern{N}, R::HyperRectangle{<:SVector{N}})

Return the intensity of the illumination pattern ip at the location r (SVector{N}) or under the cell integration hyper-rectangle R (HyperRectangle{<:SVector{N}}).

Every IlluminationPattern must implement these methods.

Method intensity when r isa AbstractVector{<:Length} has a default implementation converting r to SVector{N} and calling the child implementation.

source

Harmonic Illumination Pattern

The harmonic illumination pattern is represented by the Harmonic type

SIMIlluminationPatterns.Harmonic — Type
Harmonic{T} <: IlluminationPattern{2}

2D Harmonic (sinusoidal) illumination pattern.

The intensity is given by

\[ I(r) = 1 + (m/2) * cos(2π * (k ⋅r + ϕ))\]
